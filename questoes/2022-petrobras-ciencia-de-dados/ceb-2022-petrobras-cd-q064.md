**64** No código a seguir, `DecisionTreeClassifier` é um classificador que recebe como entrada dois *arrays*: um *array* `X`, de valores inteiros, contendo os rótulos de classe para as amostras de treinamento; e um *array* `Y`, esparso ou denso, contendo as amostras de treinamento.

```python
>>> from sklearn import tree
>>> X = [[0, 0], [1, 1]]
>>> Y = [0, 1]
>>> clf = tree.DecisionTreeClassifier()
>>> clf = clf.fit(X, Y)
```
