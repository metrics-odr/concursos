# 🔎 Acervo de estudo — CGU AFFC · Ciência de Dados

Onde e como estudar cada disciplina do edital. Fontes curadas + atalhos de busca por tópico.

> [!TIP]
> Gerado por `python3 scripts/gerar_acervo.py`. Para incluir uma fonte, edite [`curadoria.json`](curadoria.json) (ou peça ao Claude) — vídeos por tópico ficam em [`videos.json`](videos.json) — a rotina semanal também faz isso.

## Como estudar (geral)

- Ciclo semanal: teoria curta (1 tópico/dia) → 20–30 itens Cebraspe do tópico → revisão pelos erros.
- Cebraspe cobra interpretação e aplicação: estude pelo texto do edital (verbos 'distinção', 'relação', 'limites') e treine C/E com justificativa.
- Um errado anula um certo: deixe em branco quando a confiança for < ~60%.
- Discursiva: 1 texto por semana (30 linhas complementares; 60 linhas situação-problema de Ciência de Dados).
